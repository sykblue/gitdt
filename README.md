# 바퀴살 공방 (시험용 프로토타입)

동네 자전거 수리 공방을 가정한 4페이지짜리 정적 사이트입니다. 실제 가게가 아니에요.

- 디자인 기준: [DESIGN.md](DESIGN.md)
- 보는 법: `index.html`을 브라우저로 열면 됩니다. 빌드 과정은 없어요.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 메인 |
| `pages/services.html` | 수리 항목과 가격 |
| `pages/process.html` | 맡기는 순서 |
| `pages/visit.html` | 찾아오는 길 |
| `css/style.css` | 모든 페이지가 함께 쓰는 스타일 |

모든 링크는 상대 경로라서 GitHub Desktop으로 올린 뒤 GitHub Pages(Settings → Pages → `main` 브랜치, `/ (root)`)로 그대로 공개할 수 있어요.
